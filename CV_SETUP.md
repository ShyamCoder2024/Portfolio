# How to Add Your CV for Download

## Step 1: Add Your CV File

You have two options:

### Option A: Public Folder (Recommended)
1. Put your CV file in the `public` folder
2. Name it something like: `Shyam_Mangaonkar_CV.pdf`
3. Path will be: `/Users/shyamsudhirmangaonkar/Desktop/Portfoliio/public/Shyam_Mangaonkar_CV.pdf`

### Option B: Assets Folder
1. Put your CV in: `src/assets/Shyam_Mangaonkar_CV.pdf`
2. Requires import statement in code

**I recommend Option A (public folder)** - it's simpler!

## Step 2: Update the Code

Once your CV is in the `public` folder, the Download CV button will automatically work!
